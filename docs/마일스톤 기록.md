# 마일스톤 기록 (M1~M19)

> 끝난 마일스톤의 결정·체크·"계획과 다르게 한 것"·"하지 못한 것" 기록이다 (M1~M8은 `.claude/CLAUDE.md`, M9~M19는 `plans/`로 나누기 전의 CLAUDE.md에서 옮김). 지금 하는 일은 `plans/current-milestone.md`. 결정의 자세한 이유는 ADR(`아키텍처 결정 기록 (ADR) — 프로젝트 전반.md`)에 있다.

중장기 1단계(기본 완성도와 안정성)를 세 마일스톤으로 나눠 이 순서로 진행한다. 각 마일스톤이 끝나면 테스트·미리보기 확인 후 커밋하고 여기 체크한다.

## 합의한 결정
- 기본값: 기존 부가 기능 중 **HTML 렌더링만 기본 off**로 바꾼다 (AI가 쓴 JS를 실행하므로). 폰·게임·캐릭터 이미지·정규식은 기본 on 유지. 앞으로 추가하는 기능은 모두 기본 off. 이미 설정을 저장한 사용자의 값은 건드리지 않는다.
- 번역 저장: **공용 번역 캐시** (원문 해시, 언어) → 번역문. 채팅·폰·게임이 같이 쓰고, 같은 문장은 세션·분기·재플레이에서 다시 요금을 내지 않는다. 원문이 바뀌면 해시가 달라져 자연히 무효.
- 실행 관리 범위: **모든 유료 AI 호출을 TaskManager로 통일 + 호출 기록·사용량(ResourceManager 1차) + 화면**. 예산 한도(막기)는 다음 단계.
