# 슬래시 커맨드·빠른 답장 (STscript 호환)

샌드캐슬은 SillyTavern의 STscript를 읽어 실행한다 (ADR-025, roadmap 5-E-20-5·5-E-20-6).
코어 플러그인 **슬래시 커맨드·빠른 답장**(기본 꺼짐)을 켜면, 입력칸에서 `/`로 시작하는 글과 빠른 답장 버튼이 스크립트로 돈다. 대화 화면과 폰 대화방 둘 다.

- 범위: 스크립트 언어(문법·흐름·변수·매크로·수학·글자)는 SillyTavern과 끝까지 맞춘다. 앱 기능 커맨드는 샌드캐슬에 대응하는 것만.
- 비용: 스크립트는 사용자가 보내거나 버튼을 눌렀을 때만 돈다(자동 실행 없음). AI를 부르는 커맨드는 한 번 실행에 **AI 호출 상한**(설정 > 빠른 답장, 기본 5·최대 50)까지 — 넘으면 오류로 멈추고 넘은 호출은 하지 않는다.
- 상한: 반복 하나 1000바퀴, 한 실행 1만 단계. 넘으면 어디서 멈췄는지 알린다.
- 확인: 사용자가 쓰는 실제 QR 4개(`src-tauri/tests/sillyTavern/qr` — 분석·자동사냥·무물·뉴스)가 끝까지 도는 시험 (`src/features/slash/realQr.test.ts`).

## 문법

| 문법 | 지원 | 비고 |
| --- | --- | --- |
| `/커맨드 key=값 이름 없는 인자` | ✅ | 값: 따옴표·묶음·`[목록]`·`{객체}` |
| `\|` 파이프, `{{pipe}}` | ✅ | 이름 없는 인자가 없으면 앞 결과를 넘김 |
| `\|\|` 파이프 끊기 | ✅ | |
| `{: … :}` 묶음, `{: … :}()` 바로 실행 | ✅ | 묶음은 만든 자리의 변수를 본다 |
| 묶음 인자 `{: a=1 … :}`, `{{var::a}}`·`{{arg::a}}` | ✅ | |
| `/:세트.버튼`, `/:변수 a=1` | ✅ | |
| `//`·`/#` 주석, `/* */` 블록 주석 | ✅ | |
| `\|`·`\{`·`\}`·`\"` 이스케이프 | ✅ | |
| 따옴표 | ✅ | 인자가 따옴표로 **시작할 때만** 묶음 (본문 중간의 `"`는 글자) |
| `/`로 시작하지 않는 조각 | ✅ | 오류 없이 건너뜀 (SillyTavern과 같음) |
| 파서 플래그 `/parser-flag`, 디버거 `/breakpoint` | ❌ | |

## 빠른 답장 파일

- 세트(`.json`, `qrList`)와 버튼 하나(`.qr.json`)를 여러 개 한 번에 가져온다 (설정 > 빠른 답장 > SillyTavern에서 가져오기). 버튼 파일들은 세트 하나로 묶인다.
- 자동 실행(시작할 때·보내기 전·AI 답장 뒤 등)은 가져오지 않는다 — 누를 때만 돈다.
- 세트는 전역·프리셋 전용·캐릭터 전용으로 나눈다 (정규식과 같음).

## HTML 블록에서 부르기 (`triggerSlash`)

HTML 코드 블록(JS가 도는 iframe) 안에서 SillyTavern처럼 부를 수 있다. 블록을 **눌렀을 때만** 실행하고, 연달아 부르면 차례로 하나씩 돈다. 결과는 돌려주지 않는다(Promise는 바로 빈 글).

```js
triggerSlash(`/setvar key=choiceText "${escaped}"`);
triggerSlash(`/setinput ${parsed.originalText}`);
triggerSlash('/run QR이름');
```

## 알아 둘 것

- 본문 안의 이스케이프하지 않은 `|`는 커맨드 구분이다. 예: 뉴스 QR의 `/setvar` 본문은 `title: [Title]`에서 잘린다 (SillyTavern에서도 같음). 본문에 `|`를 쓰려면 `\|`로.
