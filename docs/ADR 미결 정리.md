# ADR 미결 항목 정리 (감사표)

> 2026-11-18, `plans/roadmap.md` 1-F-2. ADR의 Proposed·Deferred·"미결·후속 작업"을 **코드와 대조**해 결론을 낸 표다. 결론은 ADR 본문에도 반영했다. 코드에서 찾지 못한 것은 "구현됨"이라 쓰지 않고 "찾지 못함"으로 적었다.

분류: **구현됨**(ADR을 Accepted로) · **남음**(roadmap 번호로 이관) · **보류**(재개 조건을 ADR에 적음) · **폐기**

## 미병합 브랜치 `claude/game-assets-storyplan`

- 내용(커밋 하나, 20개 파일·+2037줄): 에셋 추가/삭제 커맨드(`asset_store.rs`), StoryPlan(`story_plan.rs`, ADR-019), capabilities 강제, 테스트 픽스처. roadmap 4-A·4-B-1·4-D의 큰 부분이다.
- dev와의 거리: 기준에서 dev가 173커밋 앞서 있고, 병합 시 충돌이 **5개 파일**(`commands/game_engine.rs`, `game/mod.rs`, `game/npc.rs`, `game/runtime/mod.rs`, `game/template.rs`) + `lib.rs`의 명령 등록. 새 마이그레이션은 없다(`game_story_plans` 표는 이미 있음).
- 추천: 1-F-2-3으로 **병합**(충돌 해결 → 게임 테스트·`cargo test` 통과 → 브랜치 코드 검토). 병합하면 위 표의 "브랜치에만" 항목이 구현됨으로 바뀐다. 검토 없이 합치지 않는다. 결정은 사용자.
