# 성능 측정 (CLAUDE.md 1-D-5)

> 2026-11-17. "먼저 재고, 기준을 넘는 곳만 고친다".
> 백엔드: `cd src-tauri && cargo test --release --lib perf_tests -- --ignored --nocapture` (`src-tauri/src/perf_tests.rs`)
> 화면: 브라우저 미리보기(개발 빌드, 가짜 백엔드)에 큰 데이터를 넣고 메인 스레드가 막힌 시간(long task)·DOM 수를 잼. 개발 빌드라 배포 빌드보다 느리다.

## 기준

| 동작 | 기준 |
| --- | --- |
| 화면 열기 (대화·갤러리) | 메인 스레드가 막히는 시간 합 2초 이하 (개발 빌드) |
| 백엔드 조회 | 300ms 이하 |
| 꺼진 플러그인 | 시작 때 그 기능의 데이터를 읽지 않음 |
