# 배포 (CLAUDE.md 1-E, ADR-010)

## 버전

- 버전은 `package.json` 한 곳. `tauri.conf.json`은 `"version": "../package.json"`로 읽고, `Cargo.toml`은 스크립트가 맞춘다.
- 올리기: `pnpm version:set 0.2.0` → `CHANGELOG.md`에 그 버전 칸 → `cd src-tauri && cargo check`(Cargo.lock 갱신) → 커밋
- 확인: `pnpm version:check` (CI도 매번 확인)

## 릴리스 만들기

```bash
git tag v0.2.0
```

```bash
git push origin v0.2.0
```

- `.github/workflows/release.yml`이 Windows 설치 파일(NSIS·MSI)과 Android APK를 만들어 GitHub 릴리스 **초안**에 올린다.
- 초안을 확인하고 GitHub에서 "Publish release"를 누르면 공개된다. 앱의 "새 버전 확인"은 공개된 릴리스만 본다.
- 태그와 `package.json` 버전이 다르면 멈춘다.

### Android 서명 키 처음 만들기 (한 번)

키 파일은 **저장소 밖**에 둔다 (예: `C:\keys\`). JDK의 keytool:

```bash
keytool -genkeypair -v -keystore C:/keys/sandcastle-release.jks -alias sandcastle -keyalg RSA -keysize 4096 -validity 10000
```

내 PC에서 배포용 APK를 만들 때는 `src-tauri/gen/android/keystore.properties` (이미 .gitignore에 있음):

```
storeFile=C:/keys/sandcastle-release.jks
password=<비밀번호>
keyAlias=sandcastle
```

CI용 GitHub Secrets (저장소 Settings → Secrets and variables → Actions, 또는 gh CLI):

```bash
base64 -w0 C:/keys/sandcastle-release.jks | gh secret set ANDROID_KEYSTORE_BASE64 --repo dily311/sandcastle
```

```bash
gh secret set ANDROID_KEYSTORE_PASSWORD --repo dily311/sandcastle
```

```bash
gh secret set ANDROID_KEY_ALIAS --repo dily311/sandcastle --body sandcastle
```

비밀값이 없으면 릴리스 워크플로는 APK를 건너뛰고 경고만 남긴다.

## 구글 드라이브 클라이언트 (2-D, 한 번)

드라이브 동기화에는 구글 클라우드의 OAuth 클라이언트가 필요하다. **저장소에는 넣지 않는다** — 내 PC는 `src-tauri/google-oauth.env`(.gitignore의 `*.env`), CI는 GitHub Secrets. 없으면 드라이브 연결이 없는 빌드가 되고(설정 > 동기화에 "이 빌드에는 구글 드라이브 연결이 들어 있지 않음"), 폴더 동기화·파일로 주고받기는 그대로 된다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 새 프로젝트 (예: Sandcastle)
2. API 및 서비스 → 라이브러리 → **Google Drive API** 사용 설정
3. Google 인증 플랫폼(OAuth 동의 화면): 대상 **외부**, 앱 이름·지원 이메일. 데이터 액세스(범위)에 **`.../auth/drive.appdata`** 하나만 추가
   - "테스트" 상태에서는 테스트 사용자로 넣은 계정만 로그인되고, 로그인이 7일마다 풀린다. 오래 쓰려면 "프로덕션"으로 게시 — 콘솔이 확인(심사)을 요구하면 그 안내를 따른다
4. 클라이언트 → 클라이언트 만들기 → 애플리케이션 유형 **데스크톱 앱** → 클라이언트 ID와 보안 비밀 복사
5. 내 PC: `src-tauri/google-oauth.env`

```
SANDCASTLE_GOOGLE_CLIENT_ID=….apps.googleusercontent.com
SANDCASTLE_GOOGLE_CLIENT_SECRET=…
```

6. 릴리스 CI:

```bash
gh secret set GOOGLE_CLIENT_ID --repo dily311/sandcastle
```

```bash
gh secret set GOOGLE_CLIENT_SECRET --repo dily311/sandcastle
```

- 데스크톱 앱 유형의 "보안 비밀"은 구글 문서상 앱 안에 들어가는 값이라 비밀로 지켜지지 않는다. 그래도 저장소에는 넣지 않는다.
- Android는 아직 없다 (서명 키를 만든 뒤 Android용 클라이언트 — 패키지 이름 + 서명 키 SHA-1 — 와 네이티브 로그인으로).

## 업데이트 알림 (1-E-2)

- 앱은 GitHub Releases(`dily311/sandcastle`)의 최신 공개 릴리스만 본다. 내려받거나 설치하지 않고 릴리스 페이지를 열어 준다.
- 설정 > 기본 설정 > 업데이트: "업데이트 확인" 버튼, "앱을 켤 때 새 버전 확인"(기본 꺼짐).
